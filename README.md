Project Details:

Project Name: Undercooked

Project Description (simplified): A website rendition of the popular game "Overcooked" but in real life.

Project Description (detailed): The website rendition of the popular game "Overcooked" but in real life using real computers acting as stations. The host can create a game room and players and stations can join the game. Players have to run around in real life to different computers to use the stations to prepare food. There are 3 types of connections: Host, Player/Client, and Station. Host hosts the game, decides who gets to join, and starts the game. Player/Client joins the game and interacts with the stations to prepare food. Station could be a dispenser and other. The repository is NOT complete - 1/8/2026.
